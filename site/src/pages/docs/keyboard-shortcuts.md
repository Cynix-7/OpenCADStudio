Every shortcut below matches the app's default bindings. You can view and
customize them anytime with the **Keyboard Shortcuts** dialog
(<kbd>F1</kbd> help → keyboard shortcuts, or the `CUI` command).

> **Note:** on macOS, use <kbd>⌘</kbd> (Cmd) wherever you see
> <kbd>Ctrl</kbd> below.

## Function keys

| Key | Action |
|---|---|
| <kbd>F1</kbd> | Help |
| <kbd>F2</kbd> | Toggle command history |
| <kbd>F3</kbd> | Toggle object snap (OSNAP) |
| <kbd>F7</kbd> | Toggle grid |
| <kbd>F8</kbd> | Toggle ortho mode |
| <kbd>F9</kbd> | Toggle snap |
| <kbd>F10</kbd> | Toggle polar tracking |
| <kbd>F11</kbd> | Toggle object snap tracking (OTRACK) |
| <kbd>F12</kbd> | Toggle dynamic input |

## Command line

| Key | Action |
|---|---|
| <kbd>Enter</kbd> | Finalize / confirm current input |
| <kbd>Space</kbd> | Run command / confirm |
| <kbd>Escape</kbd> | Cancel current command |
| <kbd>↑</kbd> / <kbd>↓</kbd> | Previous / next command history |
| <kbd>Tab</kbd> | Cycle through dynamic input fields / autocomplete |
| <kbd>←</kbd> / <kbd>→</kbd> | Move caret in text fields |

## Pro tips

- **<kbd>Space</kbd> is your best friend.** In CAD, pressing Space repeats or
  confirms the current action — muscle memory beats clicking.
- **Double-click on a dimension** opens its properties. Double-click on text
  opens the text editor.
- Press <kbd>Escape</kbd> once to cancel a command, twice to deselect
  everything.
- You can run any command from the keyboard: type `TRIM`, `OFFSET`, `MIRROR`,
  `HATCH`… at the command line. See the
  [drawing basics](/docs/drawing-basics/) page for the most useful ones.

## Customizing shortcuts

Open the **Keyboard Shortcuts** dialog (from Help or the `CUI` command) to see
every binding, remap keys, and add your own. Your custom bindings persist
across sessions in the app's local storage — no account needed.
