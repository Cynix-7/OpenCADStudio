## 00:45–01:30 THE COMMAND LINE (the 30-second habit)

Screen: type LINE, draw; type C, draw circle; autocomplete shown.

VO: "Here's the one habit that makes CAD fast: type instead of hunt. Type
LINE — or just L — and press Enter, click two points, you have a line. C for
circle. REC for rectangle. Start typing anything and suggestions appear —
press Tab to complete. Every ribbon button runs a command; you can drive
everything from the keyboard."

## 01:30–02:30 DRAFTING AIDS

Screen: F7 grid, F8 ortho, F3 object snap demo (snap to midpoint).

VO: "Precision comes from the drafting aids, all on function keys. F7 toggles
the grid. F8 locks lines to 0 and 90 degrees — ortho mode. F3 is object snap:
move near a midpoint, an endpoint, a center, and it snaps exactly. For
engineering drawings, object snap is the most important key on the keyboard."

## 02:30–03:15 MODIFY

Screen: OFFSET a line, TRIM a crossing, MIRROR a shape.

VO: "Drawing is half the story; modifying is the other half. OFFSET makes
parallel copies — that's how you build walls. TRIM cuts lines at their
crossings. MIRROR flips a shape across a line. Three commands, and you can
already build real geometry."

## 03:15–04:00 LAYERS + DIMENSIONS (flash)

Screen: LAYER quick demo; DIMLINEAR quick demo.

VO: "Two things every drawing needs. Layers — LAYER opens the manager; put
walls on WALLS and text on TEXT, color-coded, so you can toggle and lock
groups. And dimensions — DIMLINEAR, click two points, done; it measures the
geometry itself, so it's always right."

## 04:00–04:40 OPEN, SAVE, EXPORT

Screen: drag-drop DWG; Ctrl+S save; File → Export list.

VO: "Files are trivial: drag a DWG or DXF straight onto the window to open
it. Ctrl+S saves. And File → Export gives you SVG, PDF, STL for 3D printing,
STEP for manufacturing — everything free, all local, nothing uploaded."
