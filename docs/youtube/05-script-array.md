## 00:06–00:30 WHAT ARRAY DOES

Screen: two patterns side by side: a grid of chairs (rectangular) and a ring
of bolt holes (polar).

VO: "ARRAY copies an object into a pattern. Two flavors: rectangular — rows
and columns, like a grid of chairs in an auditorium — and polar — around a
center point, like bolt holes on a flange. Let's do both."

## 00:30–01:30 RECTANGULAR ARRAY

Screen: draw a small chair/desk rectangle; type ARRAY.

VO: "Here's a table. I want a grid of them. Type ARRAY — or AR, Enter. Choose
Rectangular. It asks for rows and columns — I'll do 3 rows, 4 columns, and a
spacing of 30 by 30."

[Screen: type 3 rows, 4 columns, spacing]

VO: "Enter, and there's the grid — twelve tables, perfectly spaced. Click
inside the array to edit it afterwards: change rows, columns, spacing, and
the whole grid updates. That's the magic — it stays one editable pattern, not
twelve loose copies."

## 01:30–02:30 POLAR ARRAY

Screen: flange circle + one bolt circle; type ARRAY, choose Polar.

VO: "Now the polar pattern. Here's a flange with one bolt. Type ARRAY, choose
Polar. It asks for a center point — I'll snap to the flange's center. Then
the item count: 8. Enter."

[Screen: 8 items around the flange center]

VO: "Eight bolts, evenly spaced around the circle, with the angle filled
automatically. And just like the rectangular version, click it later to change
the count, the center, or the fill angle. Need 12 holes instead of 8? Two
clicks."

## 02:30–03:10 REAL-WORLD COMBO

Screen: quick demo — bolt pattern + polar array of a repeating detail.

VO: "Here's the real-world combo: draw the flange, place one bolt with proper
layers, polar-array it, and your drawing is done. This is why array is one of
the most-used commands in CAD — one piece of geometry, patterned perfectly,
instead of drawing eight bolts by hand."
